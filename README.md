
# OrbitFM

A crossplatform file manager


## Installation

Try OrbitFM with nix

```bash
  nix run github:MOLf1i/OrbitFM/develop
```
Cargo (UNIVERSAL)

```bash
  cargo install --git https://github.com/MOLf1i/OrbitFM
```
